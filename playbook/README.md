## One-page summary

| Question | Answer |
| --- | --- |
| How many per batch | 8–12 sites, ~2 hours. Past 12 you start losing records. |
| Who first | `P0` (proven free, no badge) → `P1` (account needed) → `P2` (volume). `P3` needs a decision, `X` is never. |
| Ordering rule | No-account sites first; all account sites in one session so you log in once. |
| What counts as done | Receipt / queue state / live listing page. A filled form is not done. |
| Recording | 1 minute per row. No record = the submission is worthless, because you cannot follow it up or reuse the learning. |
| Time per site | No-account directory 5–10 min · account required 10–20 min · download site / email pitch 15–30 min |
| Cadence | 1–2 batches per week. Review queues run from 1 week to 4 months — spreading batches keeps links landing continuously. |

## The one sentence

> The bottleneck is not the number of directories. It is **judgment** (do not waste a slot on the wrong category, a link exchange, or a false declaration) and **bookkeeping** (so the next project does not start from zero).
